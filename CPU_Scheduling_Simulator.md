# CPU Scheduling Simulator

## About the Project
The CPU Scheduling Simulator is a Python-based application that demonstrates how operating systems schedule processes for CPU execution. It provides a graphical user interface built using Tkinter.

## Features
- FCFS (First Come, First Served)
- SJF (Shortest Job First)
- Round Robin (RR)
- Priority Scheduling
- Interactive graphical user interface
- Gantt chart visualization with horizontal scrolling
- Process completion time, turnaround time, and waiting time calculations
- Comparison of scheduling algorithms
- Export results to CSV

## Technologies Used
- Python 3
- Tkinter
- CSV module

## Scheduling Formulas
- Turnaround Time = Completion Time − Arrival Time
- Waiting Time = Turnaround Time − Burst Time
- Average Waiting Time = Total Waiting Time ÷ Number of Processes
- Average Turnaround Time = Total Turnaround Time ÷ Number of Processes

## How to Run
1. Install Python 3 if it is not already installed.
2. Download the project files.
3. Open the Python file in IDLE.
4. Select **Run → Run Module**.

Alternatively, run this command in a terminal:

`python cpu_scheduling_simulator.py`
